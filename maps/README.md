# State / province maps (Incident Explorer)

One SVG per country (`<ISO2>.svg`), loaded on demand by `incident-explorer.html` when a country is opened on the world map.
Generated by `tools/build-country-maps.js` — do not edit by hand; rerun the script instead.

## Format

- `viewBox="0 0 1000 650"`, coordinates rounded to 0.1, simplified with mapshaper (Visvalingam, weighted, topology kept).
- One `<path>` per region: `id="sm-<ISO 3166-2>"`, `data-iso`, `data-name` (map name) and `data-states` = the explorer State names
  (GeoNames admin1 names, as `server/zip-geo.js` shows them) that belong to the region, joined by `|`. No styles or scripts.
- The map level equals the explorer's State level per country; finer Natural Earth levels are dissolved.

## City points (`<ISO2>-cities.json`)

One file per country, loaded on demand by `incident-explorer.html` the first time a state is zoomed into, for the city dots.

- Format: `{ country, unit: 0.1, rule, states: { "<explorer State name>": { names: "City A|City B", xy: [xA, yA, xB, yB] } } }`.
  `x` / `y` are tenths of a unit in the SVG's own `viewBox` (divide by 10), so a dot sits exactly where the paths are drawn.
- Projection: each point goes through the same mapshaper `-proj` as the paths (US: `albersusa +PR`, so Alaska, Hawaii and
  Puerto Rico move with their shapes; others: the country's own `laea`), then the same inset move (ES Canarias, PT Azores /
  Madeira) and the same fit into the viewBox. Points are not simplified.
- Cities and their names: `server/zip-geo.js` `cityPoints()` — the explorer's own State / City derivation and ambiguity rule, so a
  name here is exactly an explorer City node under that State (same strings, scoped by State).
- Location rule: City location = the postal point (GeoNames lat/lon) nearest to the mean of all postal points whose postal code resolves to that state + city (ties: first in file order).
- Left out (the page lists them as "cities without a known location"): no usable GeoNames point, a point inside a drop box
  (islets not drawn), a point outside the viewBox, or a point more than 50 viewBox units (5% of the map width) from its
  State's drawn shape (listed below). US: a State + City already read from US.txt is not re-read from PR.txt.
- "Outside own region" = placed points within 50 units of their region but not inside its simplified path (coastal /
  island postal points just past the simplified coastline); they are drawn where they project, and the page's zoom frame
  covers every placed point of the State.

## Rebuild

```
node tools/build-country-maps.js            # download, build all 22, rewrite this README
node tools/build-country-maps.js --dry-run  # validate and report only
node tools/build-country-maps.js --only US,IN --src <local geojson>   # subset (README is not rewritten)
```

After a rebuild, bump `STATE_MAP_V` (SVGs) and / or `CITY_MAP_V` (cities files) in `incident-explorer.html` so browsers fetch the new files.
