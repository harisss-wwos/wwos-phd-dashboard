Rules & Definitions

Reference for the hierarchy, ticket statuses, resolve types, age colours, SLA, and incident rules used across the dashboard. Reflects the live code.

1. Role Hierarchy

Higher rank = more privilege. Access is gated by atLeast(role). (manager and admin share the same rank.)

RoleRankNotes
user0Base / logged-in.
editor1Can comment / log on tickets ("touched").
admin2Can publish / upload data.
manager2Same access level as admin, but cannot manage users.
owner3Full access (user management, DB health, delete log entries).

2. Ticket Statuses

  • Open / in-queue (OPEN_STATUSES / OPEN_SET): Assigned, Work In Progress, Pending, Researching
  • Resolved (isResolved): Resolved or Closed

3. Resolve / Closure Types

  • Successful — ClosureCode === 'Successful' (counted as "Successful" in Agent Analytics).
  • Immediate / Auto (IMMEDIATE_AUTO): Immediately Resolved, Automatically Closed.
  • AutoSIM resolved — ResolvedByIdentity contains "AutoSIM" (resolved by the bot, not an agent).
  • Agent resolved — resolved by a real agent (the non-AutoSIM remainder).

4. Ticket Age Colours (open tickets only)

  • Green — ≤ 96 hrs (0–4 days)
  • Yellow — 96–168 hrs (4–7 days)
  • Red — 168–240 hrs (7–10 days)
  • Black — > 240 hrs (> 10 days)
  • Purple — Reopened (_reopened flag OR has a ResolvedDate while still open)

5. SLA Rule

  • SLA_HOURS = 240 (10 days). "SLA compliant" = resolution time ≤ 240 hrs from create date. Weekly SLA % is bucketed by resolved date.

6. Repeat / Historical Incidents (HI)

  • HI count parsed from RootCauseDetails via Cnt: N or Historical Incident: N. Repeat incident = HI count > 0.
  • Pet vs non-pet split: pet = RootCause contains "unsecured animal".
  • Incident-type pet special-casing:
    • Immediately Resolved / Automatically Closed + has an assignee → "First Time Pet Incident (Immediately Resolved / No Action Taken)"
    • else has RootCauseDetails → "Pet Incident (HI>0)"
    • else → "Pet Incident (Resolved by AUTO-SIM)"

7. 1st Pet Incident (tracked metric)

A resolved ticket is a "1st Pet incident" when both conditions below hold. The two categories differ only by who resolved it (ResolvedByIdentity).

  • Condition A — ClosureCode is one of:
    • Automatically Closed
    • Immediately Resolved
  • Condition B — RootCause is one of:
    • NOT APPLICABLE/No Further Action Required
    • Unsecured Animal Attack (CX Pet)
    • Unsecured Animal Attack (Non-CX Pet/ Other)
    • Unsecured Animal Evasion (CX Pet)
    • Unsecured Animal Evasion (Non-CX Pet/ Other)
  • 1st Pet incident (handled by PHD) — Condition A & B, and ResolvedByIdentity is one of our registered agent logins. Attributed to that agent (shown on their profile) and summed into the team total on Agent Analytics.
  • 1st Pet incident (handled by AUTO-SIM) — Condition A & B, and ResolvedByIdentity is exactly arn:aws:sts::511128310777:assumed-role/AutoSIM/AutoSIM. Counted only in the quarter-wide AUTO-SIM total on Agent Analytics.

8. Time Windows (Agent Analytics / Last-24)

  • Resolved 12h / 24h — resolved within the last 12 / 24 hrs relative to now.
  • Crossing 240h next 24h — open tickets currently aged 216–240 hrs.
